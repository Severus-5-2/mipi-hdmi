# 顶层集成说明 — D2/D4（连接域 + 特征汇总 → 目标总线）

> 项目：MIPI-HDMI 实时视频图像处理系统 · 方案B §2/§3 · 负责人：**张金艺**
> 目标文件：`user_source/hdl_source/design_top_wrapper.v`（工程 `td_project/camera_to_dsi_display.al`）
> 日期：2026-10-11 ｜ 位级验证：全 PASS（`run_verify_top_chain.sh`）

---

## 一、一句话

把 **detect_color_mask（颜色掩膜） → conn_label（连通域） → conn_features（特征/前4擂台）
→ target_bus（384bit）** 这条 D2/D4 链路接进顶层，并把 `box_draw` 从「自检固定框」切到
**真实检测目标框**，实现「颜色检测 → 画框」端到端闭环。

---

## 二、数据链路

```
S_video_sat ─► detect_color_mask ─┬─ O_mask  (r|b|g) ───────────► S_mask_hit ──► 伪彩(绿) / conn_label.I_mask
                                  ├─ O_mask_r/g/b ─► 颜色编码 ──► S_det_color ─► conn_label.I_color
                                  ├─ O_de/O_pix_x/O_pix_y ──────► conn_label.I_de/I_pix_x/I_pix_y
                                  └─ O_frame_done ─────────────► conn_label.I_frame_done
                                                                        │
                                          conn_label.O_cmp_*（消隐期汇总流）
                                                                        ▼
                                          conn_features（面积降序前 4 擂台）─► S_target_bus(384bit)
                                                                        │
                                                      逐槽展开 xmin/xmax/ymin/ymax/valid
                                                                        ▼
                                                                  box_draw（画框）
```

## 三、顶层改动清单

| # | 位置 | 改动 |
|:-:|:---|:---|
| 1 | 文件头 | 新增 `\`include "common_defs.vh"` |
| 2 | 信号声明区 | 新增 D2/D4 信号（`S_det_*` / `S_lbl_*` / `S_cmp_*` / `S_target_*` / `S_box_*`） |
| 3 | `u_detect_color_mask` | `I_color_sel` 由 `2'd0`(红) → **`2'd3`（三色取或）**；把 `O_de/O_pix_x/O_pix_y/O_frame_done` 由**悬空**改为**引出** |
| 4 | 新增 | `u_conn_label` + `u_conn_features` 例化；颜色编码 `S_det_color`；`target_bus` 逐槽 `generate` 展开 |
| 5 | `u_box_draw` | `SELF_TEST` 由 `1` → **`0`**；`I_box_*` 接真实目标（原为常量 0） |

> ⚠ **`box_draw` 行为变化**：D1 上板是「4 个写死的标定框 + 屏心十字」。
> 现在 `SELF_TEST=0` ⇒ 画**真实检测到的目标框**；**屏心十字准星保留**（`I_cross_en=1'b1`，640,360）。
> 若想临时回到 D1 的标定画面：把 `box_draw` 的 `.SELF_TEST ( 0 )` 改回 `1` 即可（只影响这一行）。

## 四、接线表（关键端口）

| 顶层信号 | 驱动源 | 去向 |
|:---|:---|:---|
| `S_mask_hit` | `u_detect_color_mask.O_mask`（`r\|b\|g`） | 伪彩仲裁 + `conn_label.I_mask` |
| `S_det_mask_r/g/b` | `O_mask_r / O_mask_g / O_mask_b` | 颜色编码 |
| `S_det_color[1:0]` | `r?红 : b?蓝 : g?绿 : 未分类` | `conn_label.I_color` |
| `S_det_de / S_det_px / S_det_py` | `O_de / O_pix_x / O_pix_y` | `conn_label.I_de / I_pix_x / I_pix_y` |
| `S_det_fdone` | `O_frame_done` | `conn_label.I_frame_done` **和** `conn_features.I_frame_done` |
| `S_target_bus[383:0]` | `conn_features.O_target_bus` | `box_draw` 4 槽展开 |
| `S_target_cnt[2:0]` | `O_target_valid_cnt` | （预留，当前未消费） |

> 🔴 **铁律**：`conn_label` 的 `I_de / I_mask / I_pix_x / I_pix_y` **必须全部取自
> `detect_color_mask` 的 `O_*`**（它们互相严格同拍对齐）。不要改成 `S_hdmi_de / S_pix_x_2d`。

## 五、资源（D2/D4 新增）

| 模块 | 主要资源 |
|:---|:---|
| `conn_label` | 等价表 32×6 FF + 双 bank 游程缓冲 + 统计累加器 + 64 FF（颜色） |
| `conn_features` | 4 槽 × 91 bit ≈ **364 FF** 擂台（无 BRAM、无乘法器） |
| 顶层新增 | `generate` 展开纯连线，0 额外寄存器 |
