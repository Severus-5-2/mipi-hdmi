## 0. 基线与上板现象溯源（2026-10-06 实拍）

当前链路：

```
CSI解包 → raw10_unpacket_2lane(+BLC 64) → demosaic(BGGR) → AWB(灰度世界)
       → DDR → gamma_lut(γ=1/2.2) → chroma_denoise → sat_enhance → MUX(4路) → OSD → HDMI
```

已完成：灰度 / 二值 / Sobel / 4 路拨码切换 / Gamma / BLC / 色度降噪 / 饱和度增强 / AE 自动曝光。

**上板实拍的 5 个现象与本方案的对应关系**（这是本方案的立项依据）：

| 实拍现象 | 根因定位 | 对应任务 |
|---|---|---|
| 室内逆光：人物成剪影，AE“不起作用”，但按键有效 | `ae_meter` 用**全帧平均**，窗外亮区把均值拉高，AE 误判“已达标”而停止加曝光 | **A1 中心重点加权测光** |
| 整体发绿、肤色发青、颜色闷 | **无 CCM**（sensor 光谱响应 ≠ sRGB），饱和度增强只能拉饱和度、救不回色相 | **A2 CCM 3×3 色彩校正** |
| 画面发雾、不够清楚 | ① BLC 刚修复、黑位待验证 ② 无锐化 ③ 无 CCM | **A0 黑位验证 + A5 锐化 + A2 CCM** |
| 暗光下 Sobel 漏检；拉高曝光后全是椒盐噪点 | Sobel 是高通，高增益噪声落在通带被放大；**固定阈值**两头堵 | **A3/A4 Sobel 预平滑 + 自适应阈值** |
| 室内整体偏暗 | 测光偏差 + 靶亮度偏低（已由 112→120） | **A1 + 靶亮度默认 120** |

## 2. 任务分解 A0~A7

### A0 黑位验证（0.5 天，**必须先做**）
- 操作：**盖住镜头**，看屏幕是否接近纯黑。
- 仍发深灰 → `.I_camera_black_level(10'd64)` 上调到 80 / 96；
- 出现“死黑块 + 亮噪点” → 减过头，下调到 48。
- 目的：确认 BLC 修复生效，后续所有画质模块的判断才有基准。

### A1 中心重点加权测光（`ae_meter` v3）
- **位置**：`ae_fix/ae_meter.v`，**对外接口保持不变**（`I_de / I_rgb / O_Y_avg / O_frame_toggle`），`ae_set.v` 与 top 不用改。
- **做法**：在现有像素流水上加行列计数器，把画面切成 3×3 九宫格，中心权重 4、边中 2、四角 1，求加权均值。
- **关键实现点**：
  - 9 个独立的 32bit 区累加器（纯寄存器，9×32 = 288 FF，成本极低），每拍只更新其中 1 个（9 选 1 MUX + 一次加法），时序不变差；
  - 除数 `D = Σ(wᵢ × nᵢ)` 是**编译期常量**（nᵢ 由分区边界决定），沿用现有“乘常数 K 再 `>>32`”的除法结构，运行时只多一次乘法；
  - 权重做成 `parameter W_CENTER / W_EDGE / W_CORNER`，方便上板调。
- **验证**：Python 闭环仿真——构造“中心暗 + 四周亮”的逆光帧，对比全帧平均 vs 加权平均，确认 AE 会继续加曝光（画面变亮）；再跑 7 组静态 + 3 组切换场景确认无振荡。
- **工期**：1 天（含仿真）+ 0.5 天上板验证。

> **A1 定稿参数（已实现，2026-10-06）**
> - 权重 **(8,2,1)**（中心 8×、边中 2×、四角 1×），除数 D=2048640，**K=2097**
> - 权重在累加时以**移位**施加（`acc += Y<<w_sh`），帧末无乘加树，时序不变差；代价是权重必须是 2 的幂
> - x/行计数器放流水第 2 级、靠回绕自归零（921600 = 1280×720 整除），不需要帧末复位
> - `METER_MODE` 参数：1=加权（默认）/ 0=全帧平均（旧行为），供上板 A/B 对比
> - 换档对照表：(4,2,1)→K=2621 ｜ (8,2,1)→K=2097 ｜ (8,4,1)→K=1498 ｜ (2,1,1)→K=4194
> - 位级验证：均匀画面两模式均 = 128（归一化正确）；逆光 190→138；中心人脸 60→91

### A2 CCM 3×3 色彩校正（治“雾感/偏绿”的治本项）
- **位置**：插在 **DDR 读端 → `gamma_lut` 之前**（即线性域、显示时钟域 74.25MHz），不动写端，改动面最小。
- **做法**：`R' = (c00·R + c01·G + c02·B + 128) >>> 8`，系数用 8bit 定点（×256）。
- **关键实现点**：
  - 两级流水：第 1 拍做 9 个乘法，第 2 拍求和 + 限幅（每级 ≤4 级逻辑，满足 13.3ns 预算）；
  - **每行系数和必须 = 256**（定点域的白点守恒），否则白纸会偏色——这是硬指标；
  - 默认矩阵（占位，需标定）：
    ```
    410  -128  -26     (行和 256)
    -77   358  -26     (行和 255)
    -26  -102  384     (行和 256)
    ```
- **验证**：① Python 位级扫描全量程，确认无溢出、单调、无尖刺；② 灰色输入（R=G=B）经 CCM 后必须仍相等；③ 上板用白纸/灰卡微调。
- **工期**：2 天（代码 1 天 + 标定 1 天）。

### A3 + A4 Sobel 增强：预平滑 + 自适应阈值

> **2026-10-06 实测定位（室内高曝光）**：Sobel 模式下边缘图满屏椒盐白点，
> 暗光下又检测不出人体轮廓，必须拉到高曝光才出边缘——但那时噪点更多。**结论：模块没写错，是架构缺料。**
>
> 噪声三层叠加：① AE 加曝光/增益 → sensor 散粒/读出噪声抬高；
> ② Sobel 输入取自 `S_video_bright`（Gamma **之后**），Gamma 暗端斜率最陡（`LUT[16]=72`），
> 把暗噪声进一步拉开；③ Sobel 是高通，噪声正好落在通带，越过写死的 `EDGE_TH=130` 就成白点。

- **A3 预平滑**：3×3 高斯 `[1 2 1 / 2 4 2 / 1 2 1] / 16`（即 `>>4`）。
  ⚠️ **更正早版说法**：写法上直接照抄 `sobel_3x3.v` 的行缓存结构即可，
  但**必须做成独立模块并自带 2 块行缓存**（1280×8 each）——
  高斯的输出才是 Sobel 的输入，两级 3×3 窗口无法共用同一批缓存。
  孤立噪声是高频脉冲，高斯一卷幅度掉到 1/4 以下；真实边缘是连续结构，保留 80% 以上。
- **A4 自适应阈值**（两档，先易后难）：
  1. **首选·阈值与 AE 增益联动**：`ae_set` 里已有当前增益 `ag`，引一根线即可，
     `EDGE_TH = TH_BASE + f(ag)`（增益 16x→126x 时阈值从 ~90 爬到 ~180）。
     半自适应：不用再加统计模块，成本接近零；缺点是它跟随"增益"这个代理量，而不是实际噪声水平。
  2. **进阶·全帧梯度统计**：照抄 `ae_meter` 框架，统计 `G_avg = Σ(|Gx|+|Gy|) / 像素数`，
     `TH = G_avg × K`（K 默认 2.0，可按键调），并设下限 `TH_MIN=40` 防全噪帧把阈值拉穿。
     - 暗光：`G_avg` 小 → 阈值自动降 → 真实边缘能出来；
     - 高增益：`G_avg` 大 → 阈值自动升 → 噪声进不来。
- **滞回（顺手加）**：`mag > TH` 置边缘、`mag < TH−32` 才清除，边缘线更连贯且不闪。
- **二值化一起做**：`binarize` 的 `THRESHOLD=160` 也是写死的，同一根阈值线接过去即可，边际成本为零。
- **可选**（若仍有噪点）：把 Sobel 移到 Gamma **之前**的线性域做（线性域信噪比更真实）。
- **验证**：Python 对同一帧加噪图像对比"固定阈值 vs 自适应阈值"的边缘点数 / 噪点数，
  目标：**噪点下降 ≥50% 且真实边缘保留 ≥90%**。

### A5 锐化 USM（视觉增强，兼治“不清楚”）
- 做法：`high = in − 3×3均值`；`out = clamp(in + (k·high)>>>4)`，k 可调（默认 4，即 0.25 倍）。
- 位置：`sat_enhance` 之后（显示域）。窗口复用 `denoise_fix/line_delay_ram.v`。
- 流水：窗口构造 1 拍 → 高频 1 拍 → 乘加 1 拍，共 3 拍。
- 演示价值：拨码一键对比“锐化开/关”，比升分辨率的观感提升大得多，且成本极低。

### A6 直方图均衡（赛题原文点名）
- **结构**：256-bin 直方图 BRAM（双口，乒乓：帧 N 统计、帧 N+1 用帧 N 的 CDF 映射，帧末交换）。
- **保持色调**：在 YCbCr 域替换 Y（Cb/Cr 不变），转换代码直接复用 `chroma_denoise` 里已有的 RGB↔YCbCr；映射用 `Y' = 255·CDF(Y)/N` 查表实现。
- **必须加 α 混合**：`Y_out = α·Y_he + (1−α)·Y_in`，默认 α=0.5，可按键调。
  ⚠️ 不加的话暗光下 HE 会把噪声一起拉爆，反而更糟——这是 HE 最常见的翻车点。
- **降采样兜底**：若 BRAM 紧张，统计时每 4 个像素采 1 个。
- **演示**：拨码对比“HE 开/关”，暗场景效果最震撼。

### A7 风格化 + 区域填充（扩展1）
- **卡通化 / 素描**：强平滑（`chroma_denoise` 加强版或 5×5 均值）+ Sobel 边缘黑线叠加 + 可选色阶量化（每通道量化到 4 级）。纯硬件便宜、演示炸裂，而且**边缘提取已经含在里面**。
- **区域填充**：真 flood-fill（迭代算法）在纯硬件里不现实，用两条替代路线：
  1. **扫描线边界填充**：每行找第一条 / 最后一条边缘，中间填单色——行内状态机即可实现，观感就是“区域填充”；
  2. **连通域标签着色**（推荐）：直接复用队友甲的连通域输出 `label`，每个 label 分配一个伪彩色 → 这是**真·区域填充**，且和方案 B 共用一套模块，两人各赚一个功能点。
- **伪彩边缘**：轮廓着彩虹色 / 热力色，作为第 3 种风格化模式。

## 4. 验收标准（可量化）

1. 逆光场景（人站窗前）：人物不再是剪影，且窗户不过曝成纯白块。
2. 白纸 / 灰卡：R≈G≈B（偏差 ≤3），画面不再整体发绿。
3. 锐化：开关对比下细节（文字、纹理）肉眼可辨增强。
4. Sobel：暗光下能检到人体边缘；拉高曝光后噪点数量下降 ≥50%（对比修复前照片）。
5. 全部模式连续 10 分钟无花屏、无卡死。

## 6. 分辨率决策点（第 2 周末）

**主线保持 720p60。** 只有在“全部功能上板稳定 + 文档已起步 + 剩余 ≥4 天”时才开分支尝试 1080p30，试不成绝不合并回主线。

理由（数字）：
- SC520CS 全分辨率下 **1080p 最高 30fps**，帧率减半，Sobel / 帧差 / 跟踪演示会明显变卡；
- 输出 1080p60 像素时钟 **148.5MHz**，时序预算从 13.3ns 收到 **6.7ns**，chroma_denoise / sat_enhance / CCM 全部要重新流水化；
- 相机 30fps + 显示 60fps 需帧重复或缓存重构，正是“花屏 / 缓存溢出”的高发区；
- **评分表里没有分辨率这一项，稳定性却单列一条** —— 收益远小于风险。
