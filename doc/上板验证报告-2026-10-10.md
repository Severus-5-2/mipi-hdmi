## 五、过程中解决的关键问题

### 5.1 TD 工程源文件添加（阻塞 4 小时的核心坑）

**现象**：综合报 `HDL-8007 ERROR: pix_coord_gen / box_draw / osd_coord / detect_color_mask is a black box`，
伴随 `HDL-7144 instantiate unknown module`。

**根因**：TD 打开工程时**按自身内部状态回写 `.al` 工程文件**，
外部（编辑器/git）手工添加的条目不生效。实测三次：
21:01 回写后剩 62 条 / 21:15 新增条目归零 / 21:19 剩 63 条。

**正确做法**：走 GUI `Source → Add Source...` → Add Source Wizard → Design files → Add Files。
加完后 `.al` 稳定 67 条，不被回写抹掉。

**验证入口**：Hierarchy 面板左下角 **`Compile Order`** 标签页
（Hierarchy 树只显示模块层次，看不到完整文件清单 —— 之前一直找错地方）。

### 5.2 其他踩坑记录

| 问题 | 解决 |
|---|---|
| `import_device -speed -3` 报 `USR-8316` | speed 必须写**正整数** `-speed 3` |
| 命令行报 7× `PRJ-9210 XML file does not exist` | **必须在 `td_project/` 目录下运行**（`.al` 内是相对路径） |
| `PRJ-8805 Runs syn_1 need to be reset first` | `launch_runs` 前必须先 `reset_runs` |
| Tcl 注释写 `[5]` 报 `invalid command name "5"` | Tcl 把方括号当命令替换，注释里不能写 `[数字]` |
| 综合前 Console 残留 `read design error` 卡 25% | 先 `Process → Reset Runs` 清僵尸运行 |
| Tcl 命令行 `elaborate` 只加载 42 个文件 | TD batch 路径解析缺陷，**只能走 GUI**（张铭晨同样卡在此） |
