# 1821 版白平衡资源优化

基线：45f713f762410fd035a5972068bde3fda60264c3。该版已由用户确认实机正常、固化及掉电自启。原 bit、完整源码和 Git 历史另存于 outputs/资源优化前备份_1821_20261030。

## 实现范围

仅将 awb.v 中两套每拍可启动的原厂流水除法器，替换为白平衡专用的 48/32 无符号逐位迭代除法器。每套复用一个减法器，保留商、余数和 50 拍完成时序。通用原厂 IP 不改，其余模块的源码和时序约束不改。

awb 的 neutral_count 必须累计至少 256 个有效中性采样组才能启动一次。因此相邻请求不会重叠 50 拍运算；专用模块不适合替换需要每拍启动的其他除法器。保持除零全一商、低 32 位余数行为。

原厂 IP 仅对输出级实施局部异步复位，内部流水继续运行。新版保留该行为：运算中复位后，尚未到达输出的在途结果仍在原时刻产生；若复位覆盖输出时刻，该结果被取消。未以清空内部状态的常见写法代替原有行为。

## 功能保持

完整采集/ISP/DDR/HDMI 链路、分层降噪、四模式显示、暗部边缘增强、多颜色检测跟踪、中文状态、彩色模式画框与告警限制、自动曝光和手动实际增益协同均沿用 1821。增益范围保持 16～175。

## 验证与交付门槛

独立数学参考逐拍比较以及真实原厂 divider_gate.v 对拍；完整 AWB 对比原实现的像素、控制、待生效增益、帧生效增益和有效除法结果。AWB 对比使用双方共用的 signal_delay 行为模型，未模拟实际 RAM 电路；RAM 源码不变。测试覆盖冷暖色、中性、随机、强色、全黑全白、短帧和运算中复位。仿真通过不等于整片形式等价或实机验收。

首轮测试发现结果计数断言忽略了复位覆盖输出时刻会取消一次结果，修正断言后重跑；原始失败记录保留，不删除或改写为通过。

最终资源以布局布线报告为准；全部时序违例为零、源清单一致且时钟/约束审查完成后方可交付候选 bit。不得将仅综合通过的输出标为可下板版本。新版本仍需实机复核；旧版回退文件保留。
