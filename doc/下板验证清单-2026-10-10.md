## 4. 正确的话，屏幕上应该看到什么（张铭晨 D1 部分）

### 4.1 叠加元素一览（坐标 x: 0~1279，y: 0~719）

| 元素 | 位置 | 颜色 | 说明 |
|:---|:---|:---|:---|
| **B0 红框** | 左上，外框 (64,64)–(256,256) | 纯红 `FF0000` | 2 px 粗边，框内不填充 |
| **B1 绿框** | 右上，外框 (1088,64)–(1279,256) | 纯绿 `00FF00` | **右边框紧贴屏幕最右列**，不应缺一段 |
| **B2 蓝框** | 左下，外框 (64,464)–(256,656) | 蓝 `00A0FF` | 与 B0 关于中线 y=360 **严格镜像** |
| **B3 黄框** | 正中，外框 (510,290)–(770,430) | 黄 `FFF200` | 框心正好 **(640,360)** |
| **白色准星** | 中心 (640,360) | 纯白 `FFFFFF` | 臂长 ±16 px、线宽 2 px，落在 B3 正中心 |
| **坐标 OSD** | 左下 x=16~112，y=688~703 / 704~719 | 黄 `FFF200` | 两行 16×16 点阵：第一行 `X:0640`，第二行 `Y:0360` |

### 4.2 两处必须互相印证（这是 D1 的核心验收点）

> **白色准星压在 B3 黄框正中心**  ⟺  **左下 OSD 读数是 `X:0640` / `Y:0360`**

准星坐标硬编码 (640,360)，OSD 数值也硬编码 (640,360)。所以**只要坐标系统正确，这两件事必然同时成立**；
一旦坐标有偏移，就会出现「准星偏出框心，但 OSD 还写着 0640/0360」这种互相打架的画面。

### 4.3 不应该出现的现象（出现即有问题）

- 框**上方或左侧拖出一大片同色色块**（历史踩过的边框判定 bug）。
- 框的**边框粗细不均**（有的边 2 px、有的 1 或 3 px）。
- 框整体**右偏/下偏 1~2 px**（准星不在 B3 正中、B1 右边框没贴到 x=1279）。
- 左下 `X:0640` 显示成 **`X:0000`** 或全是同一个字符（位宽选错的历史 bug）。
- 画面闪烁、撕裂、整屏花屏（属原有链路问题，但会盖住 D1 的现象）。

### 4.4 原有 OSD 仍应在最上层，互不遮挡

| 原有元素 | 位置 | 备注 |
|:---|:---|:---|
| 安路 Logo | 左上 (0,0)–(160,160) | 常驻 |
| 中文信息两行 | 左上 (176,16) 起 | 帧计数 / AE 增益 |
| 当前模式名 | 右上 (1184,16) 起 | 彩色 / 灰度 / 二值 / 边缘 |

几何上互不重叠（Logo 只到 x=160，信息区从 x=176 起；模式区 x≥1184 且 y≤32，而 B1 的 y 从 64 才开始）。

## 5. 掩膜部分（张金艺 D1，仅路线 B 需要看）

### 5.1 应该看到什么

| # | 现象 | 说明 |
|:---|:---|:---|
| 1 | **目标物区域变色**，背景不变 | 掩膜默认绿色 `00FF00`（`S_mask_color`，想改自己改） |
| 2 | 颜色跟随 `I_color_sel` | 拨码选红/蓝/绿时，只保留对应颜色的目标区域 |
| 3 | **掩膜在底、画框在上** | 掩膜优先级最低，不遮挡准星/框/坐标数字 |
| 4 | 掩膜边缘**不拖尾、不整行串色** | 若出现，查坐标对齐拍数（见 5.3） |

### 5.2 掩膜的取数与对齐关系（已核实，供排查用）

```
S_hdmi_de ──┬─→ sat_enhance(2 拍) ─→ S_video_sat ─→ 掩膜 I_rgb
            │                                          │
            └──────────────────────────────────────────┴─ de 与 rgb 同源
                                     ↓
                        hdmi_mixer 内部再延 2 拍：
                        S_video_data_2d / S_x_2d / S_y_2d
                        ↑ 掩膜若要叠加进画面，必须挂在这一舞台
```

- 掩膜模块**内部**把坐标对齐到自己的 3 拍流水（`PIX_DLY` 参数，接 `S_pix_x_2d` 时填 2）。
- 若路线 B 采用「不改 mixer 内部舞台、只在最后的 `S_video_data_2d` 上做选择」的接法，
  那么掩膜输出要**再延 2 拍**才与 `S_video_data_2d` 同拍 —— 具体接法以 top 维护人实现为准。

### 5.3 掩膜对不齐时的排查方向

| 现象 | 先查什么 |
|:---|:---|
| 掩膜**整体右移/下移 1~2 px** | 坐标延时的抽头拍数（`PIX_DLY` 与所接信号是否匹配） |
| 掩膜**整体左移/上移 1~2 px** | 掩膜相对 `S_video_data_2d` 少延了拍 |
| 掩膜**只认红不认蓝/绿** | `I_color_sel` 接法 + 三色阈值区间（`RED_CB/CR_*` 等参数） |
| 掩膜**大面积误判**（整屏绿） | 阈值区间过宽；或 RGB 未转 YCbCr 直接卡阈值（本模块已转，核对是否接对取数点） |
| 掩膜**闪、只有半帧** | `I_vsync` 是否接对；帧起始清零是否生效 |
| 掩膜**完全不出现** | B1（例化）与 B2（mixer 端口）是否都做了；`.al` 是否勾了 `UsedInSyn` |
