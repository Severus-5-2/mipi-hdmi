### 2. 全新中文 OSD（`user_source/hdl_source/hdmi_mixer.v`）

三个常驻区域（屏幕 1280×720，合计 320×16 px，约占屏 **0.56%**）：

| 区域 | 坐标(px) | 内容 | 宽度 |
|:---|:---|:---|:---|
| ① 帧计数 | (176,16) | 「帧数:」+ 6 位十进制 | 9 格 = 144 |
| ② AE 增益 | (176,48) | 「增益:」+ 3 位十进制 | 6 格 = 96 |
| ③ 当前模式 | (1184,16) | 「模式:」+ 彩色/灰度/二值/边缘 | 5 格 = 80 |

- Logo `anlogic_logo_rom` 仍在 `(0,0)`，`160×160`，带 alpha（占屏 2.78%）。
- 顶层端口 `I_ae_y`（帧平均亮度）已接好但**当前不显示**，需要时可随时接进来。
- 模式来源：拨码 `SW1(A4)`/`SW2(B4)` → 顶层 `S_mode_sel[1:0]`（已在像素时钟域两级同步）。

**关键实现（后续改 OSD 请沿用）**：

1. 所有区域 X/Y 起点取 **16 的整数倍** ⇒ 局部列 = `S_x_2d[3:0]`、
   字符序号 = `S_x_2d[11:4] − 常数`、行号 = `S_y_2d[3:0]`，
   **完全不需要常数除法**（旧实现有 `/24`、`/15`、`/8` 三处）。
2. 取字模某一位用**变址** `S_pf_row_bits[~lx]`，取代 16 路 `case` 展开。
3. 字符渲染分**两级流水**：第 1 拍做「区域判定 + 字符码查表」，
   第 2 拍做「字模查表 + 位选」⇒ 关键路径约 15 级降到约 7 级。
4. **Logo 搬入第 1 拍流水**，地址用**移位加法**：

   ```verilog
   wire [14:0] W_logo_addr =
                    ( {S_y_1d[7:0],       7'd0}     // y * 128 (= y << 7)
                    + {2'b00, S_y_1d[7:0], 5'd0}   // y *  32 (= y << 5)
                    + {4'd0,  S_x_1d[7:0]} );      // x
   ```

   拼接移位铁律：**字段里「尾随 0 的个数 = 左移位数」**。这里 160 = 128 + 32。
   （曾写错成 `{3'b000,y,4'd0} + {5'b00000,y,2'd0}` = y×20 ⇒ Logo 整块消失。）

### 4. 时序修复（`td_project/camera_to_dsi_display.sdc`）

补回**对称** `set_false_path`：

```tcl
set_false_path -from [get_clocks {pll_clk_24m}]     -to [get_clocks {HDMI_PIXEL_CLK}]
set_false_path -from [get_clocks {HDMI_PIXEL_CLK}]  -to [get_clocks {pll_clk_24m}]
```

- 这对时钟 74.25 : 24 = 99 : 32，是**固定相位**关系却被 TD 当作异步组，
  预算仅 0.653 ns、Logic-Level = 0 ⇒ 必然假违例。
- **必须成对写**，只加单向无效（10-07 已验证过）。
